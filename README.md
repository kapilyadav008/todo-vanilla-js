# Vanilla JavaScript To-Do App

A fully functional To-Do application built using **pure JavaScript (no frameworks)**.  
This project focuses on core JavaScript concepts, DOM manipulation, and state-driven UI design.

## 🚀 Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks (All / Active / Completed)
- Keyboard support (Enter key to add task)
- Persistent storage using `localStorage`
- Handles backward compatibility with data migration
- Clean UI with dark theme

## 🧠 Key Concepts Used
- State management with plain JavaScript
- DOM manipulation using `createElement`
- Event delegation
- Derived state (filters)
- `localStorage` persistence
- Data migration for backward compatibility
- Defensive programming (stable IDs instead of indexes)

## 📂 Tech Stack
- HTML
- CSS
- JavaScript (ES6+)

## 📌 Why this project?
This project was built to deeply understand **JavaScript fundamentals** before moving to frameworks like React.  
It demonstrates how real-world UI logic works without relying on libraries.

## 🧪 How to Run
1. Clone the repository
2. Open `index.html` in a browser
3. Start managing your tasks

## 📚 What I Learned
- How to separate data and UI
- Why stable IDs are important in dynamic lists
- How to handle real-world bugs and data evolution
- How modern frameworks internally work
